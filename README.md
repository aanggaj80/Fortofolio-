Portofolio Pribadi — Angga Saputra
Portofolio Pribadi Angga Saputra adalah situs web satu halaman yang menampilkan profil diri, riwayat pendidikan, pengalaman organisasi, galeri kegiatan sekolah, hingga informasi kontak dalam satu tempat. Fungsi utamanya adalah menjadi kartu perkenalan digital yang bisa diakses siapa saja secara online, sehingga tidak perlu lagi menjelaskan riwayat diri secara manual satu per satu. Bagi pengguna (baik pemilik maupun pengunjung), situs ini bermanfaat untuk memperkenalkan diri secara profesional kepada guru, teman, pihak sekolah, atau perekrut magang, lengkap dengan CV yang bisa diunduh dan tautan langsung ke media sosial serta lokasi (Google Maps). Situs ini bersifat statis (HTML tunggal) sehingga sangat ringan, cepat diakses dari HP maupun laptop, dan mudah untuk di-hosting gratis lewat GitHub Pages. Untuk instalasi, cukup unduh file index.html, lalu unggah ke repository GitHub (pastikan berada di root folder), kemudian aktifkan GitHub Pages melalui menu Settings → Pages dan pilih branch main dengan folder / (root); situs akan otomatis aktif dalam 1–2 menit.
